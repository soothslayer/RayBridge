# Third-party components

RayBridge integrates with [OpenAI Codex](https://github.com/openai/codex), the [Meta Wearables Device Access Toolkit](https://github.com/facebook/meta-wearables-dat-ios), [Node.js](https://nodejs.org/), [ws](https://github.com/websockets/ws), and [node-qrcode](https://github.com/soldair/node-qrcode).

Their licenses and service terms apply independently. npm dependencies retain license files in the bundled node_modules tree. Meta binaries and license/notice files are fetched by Swift Package Manager from the pinned upstream release. The local development Mac bundler copies installed runtime binaries; before distributing that bundle, include the exact runtime distributions' complete licenses/notices and satisfy signing, notarization, and applicable vendor distribution requirements.
